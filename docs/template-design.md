# 定型文の設計メモ

2026-11-03 作成。よく使う文を保存しておき、入力欄にすぐ入れられるようにする。

## 決めたこと（ユーザー確認済み）

| 項目                  | 決定                                           | 主な理由                                 |
| --------------------- | ---------------------------------------------- | ---------------------------------------- |
| 保存先                | 端末ごと（`storage.local`）。共有しない        | 記録を端末ごとに分けている方針とそろえる |
| 入れ方                | カーソルの位置に足す（選んだ範囲は置き換わる） | 丸ごと置き換える必要はない               |
| 変数（`{date}` など） | 入れない                                       | 使いたい定型文がまだ無い（YAGNI）        |
| 絞り込み              | 全チャンネル共通                               | 必要になってから考える                   |
| 呼び出し              | 入力欄の下のボタン → 検索できる一覧            | ショートカットは要らない                 |

## 入れ方

| 観点                 | **A. 貼り付けのイベントを送る** | B. クリップボードに写し、自分で貼る | C. `execCommand('insertText')` | D. Quill の DOM を書き換える |
| -------------------- | ------------------------------- | ----------------------------------- | ------------------------------ | ---------------------------- |
| Quill を壊しにくいか | ◎ Slack の貼り付けの処理を通る  | ◎                                   | ○                              | × 方針に反する               |
| 書式（Markdown）     | ○ 書式に変わる                  | ○                                   | × 記号のまま                   | △                            |
| 手数                 | ◎ 選ぶだけ                      | △ 貼る操作が要る                    | ◎                              | ◎                            |
| Slack の変更への強さ | △ 貼り付けの処理の仕様しだい    | ◎                                   | ○                              | ×                            |

**採用: A**（`lib/composer-insert.ts`）。

- 一覧を開く前に、入力欄のカーソルの位置（`Range`）を覚えておく。選んだら入力欄にフォーカスと位置を戻してから貼り付ける。
- IME で変換中のときは入れない（未確定の文字と混ざるため）。
- Slack は貼り付けで `input` イベントを出さず、空の入力欄では DOM を非同期に書き換える。そのため、貼り付けの後しばらく入力欄を見張り、文字が入ったところで下書きを始める（`entrypoints/content.ts`）。この仕組みは、自分で `Cmd+V` で貼った場合の取りこぼしも直している。
- 実機で分かった癖：Slack は、貼り付けたリストの前に空行を入れる。

## 記録との関係

- 定型文を入れた下書きは、記録に `templateIds`（入れた定型文の ID）を残す。分析で、定型文を使った記録を分けられるようにするため。
- 定型文を入れた分も、作成時間と書き直し率に含まれる。

## 編集

- オプション画面で、名前と本文（Markdown）を編集する。名前が空なら本文の 1 行目を名前にし、名前も本文も空の行は捨てる。
- 定型文がまだ無いときは、一覧からオプション画面を開ける（content script からは開けないので background に頼む）。

## 見直す条件

- 2 台で同じ定型文を使いたくなったら、`storage.sync`（合計約 100KB）か、書き出しと読み込みを足す。
- 日付などを差し込みたい定型文が出てきたら、変数を足す。
- Slack の貼り付けの処理が変わって書式に変わらなくなったら、B（コピーして自分で貼る）に戻す。
