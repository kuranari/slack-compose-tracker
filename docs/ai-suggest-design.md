# 長引いた下書きを AI に見てもらう機能の設計メモ

2026-11-03 作成。

## 目的

書きかけの下書きについて、Claude に「どう直せば早く送れるか」を提案させる。特に、書き始めて 5 分（`WARN_MS`）を超えた下書きで使うよう促す。書き直しを繰り返して長引いている場面で、その場で抜け出すきっかけにする。

## いつ呼ぶか

| 観点                   | A. 5 分で自動で呼ぶ                | **B. 5 分でボタンを出し、押したら呼ぶ** | C. いつでも呼べるボタン |
| ---------------------- | ---------------------------------- | --------------------------------------- | ----------------------- |
| 気づきやすさ           | ◎                                  | ○ バッジの色で気づく                    | △                       |
| 作業の邪魔になりにくさ | △ 書いている途中で割り込む         | ○                                       | ◎                       |
| API の費用             | 長引いた下書きごとに必ず 1 回      | 押したときだけ                          | 押したときだけ          |
| 本文が外に出る場面     | 5 分を超えたものはすべて自動で送る | 自分で決める                            | 自分で決める            |

**採用: B と C の組み合わせ**（ユーザー確認済み、2026-11-03）。

- 最初は B（5 分を超えたらバッジが押せる）にしたが、5 分たつ前でも聞きたい場面があるため、バッジはいつでも押せるようにした（C）。
- 5 分を超えるまでは「· AI」と控えめに出す。超えたら「· AI に聞く」と太字にし、バッジを数回脈打たせて目立たせる（B の「気づきやすさ」を残す）。
- 割り切り：バッジがいつでも押せるので、入力欄の右上のバッジの下にある文字はクリックできない。バッジは小さいので許容する。

## 構成

- 呼び出しは background から、公式 SDK（`@anthropic-ai/sdk`）で直接 Claude API に送る。中継サーバーは置かない。
  - API キーはオプション画面で入力し、`storage.local` に保存する。端末ごとに設定する（2 台の記録を分けているのと同じ扱い）。
  - 拡張の中からブラウザとして呼ぶため、`dangerouslyAllowBrowser` を付ける。キーは自分のもので、自分の端末の外に配らないので許容する。
- 送るのは下書きの本文だけ。チャンネル名や過去の記録は送らない。
- 提案はバッジの上に出すパネルに表示する。Slack の入力欄には書き込まない（Quill の DOM を壊さないという方針を守るため）。使うときは自分でコピーする。

## オン・オフ

本文を Anthropic に送ることになるので、使うかどうかを端末ごとに選べるようにする。

- 機能はオプション画面で **端末ごとにオン・オフでき、既定はオフ**。
- オフのとき、バッジはこれまでどおり押せない表示だけのまま（クリックは下の入力欄に通る）。

## モデルと設定

- モデルは `claude-opus-5-5`、`effort: "low"`。書きかけの短い文章の手直しなので、深く考えさせるより早く返すほうを優先した。
- 安全性の判定で断られたときに別のモデルでやり直す、サーバー側のフォールバック（`fallbacks: "default"`）を付けている。
- 提案の内容は「短く直した文案」と「長引いている理由の指摘（3 つまで）」。

## 層の分け方

| ファイル                    | 層               | 責務                                             |
| --------------------------- | ---------------- | ------------------------------------------------ |
| `lib/suggest-prompt.ts`     | ドメイン（純粋） | 指示文と、応答から提案の文字列を取り出す処理     |
| `lib/suggest-settings.ts`   | IO（storage）    | オン・オフと API キーの保存                      |
| `entrypoints/background.ts` | IO（API）        | Claude API の呼び出し                            |
| `lib/elapsed-badge.ts`      | IO（UI）         | 押せるバッジと提案のパネルの描画                 |
| `entrypoints/content.ts`    | 組み立て         | バッジが押されたら background に頼み、結果を出す |

## 見直す条件

- 押す回数が多く費用が気になったら、モデルや effort を見直す。
- 提案が役に立たないなら、指示文を変えるか、文字の履歴（`snapshots`）も渡して「どこで迷っているか」を見せることを検討する。
- 自動で出してほしくなったら、A に切り替える。
