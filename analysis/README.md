# 書き直し分析 (analysis/)

書き出した記録 (JSONL) から「書き直しの癖」を集計し、Claude Code との会話にそのまま貼れる Markdown レポートを作るツール。

## 使い方

1. 拡張機能のポップアップから **JSONL** で書き出し、リポジトリ直下の `data/` に置く (例: `data/records-2026-10-30.jsonl`)。
   `data/` は `.gitignore` 済み。本文を含むのでコミットしないこと。
2. レポートを作る。

```sh
npm run analyze -- data/records-2026-10-30.jsonl --out data/report.md --top 10
```

- `--out` を省くと標準出力に出す
- `--top N` は「書き直しの多い下書き」として詳しく載せる件数 (既定 10)
- 壊れた行は読み飛ばし、行番号を標準エラーに出す

レポートにも本文が含まれるので、出力先は `data/` にしておく。

## 指標

文字数はすべてコードポイント単位 (絵文字 1 つ = 1 字)。

| 指標             | 意味                                                                          |
| ---------------- | ----------------------------------------------------------------------------- |
| 所要時間         | 最初の入力から送信 (破棄なら入力欄が空になるまで) の時間                      |
| 最終文字数       | 送信/破棄の直前の本文の長さ                                                   |
| 1 字あたり       | 所要時間 / 最終文字数。短い文に時間がかかっているものを見つける               |
| 挿入/削除文字数  | 隣り合う履歴どうしの差分で足した/消した文字数の合計。挿入 − 削除 = 最終文字数 |
| 書き直し率       | 削除文字数 / 最終文字数。1.0 なら最終形と同じ量を一度書いて消している         |
| 削除のあった回数 | 削除を含む履歴の変化の回数                                                    |
| 最大削除         | 一続きで消した最大の文字数。大きいと「段落ごと書き直す」傾向                  |
| 前の文を修正     | mid-edit の回数。後ろの文を残したまま前の文を直した (読み返して直す癖の目安)  |

履歴の変化 1 回ごとの種類:

- `append`: 末尾に書き足しただけ
- `tail-edit`: 末尾を消して書き直した (書きながらの言い直し)
- `mid-edit`: 前の文を直した

分布は中央値と p90 (上位 10% の境目)。切り口は全体 / 送信 / 破棄 / チャンネル / スレッド。

### 注意

- 履歴は約 10 秒ごとに変化があったときだけ取るため、10 秒以内に消して打ち直した分は見えない。削除量は **下限** として読む。
- 破棄の記録の本文は「空になる直前」の本文。最後に全消しした分は削除に数えない。
- 「書き直しの多い下書き」は書き直し率ではなく削除文字数で並べる (短文の 1 字修正が上位を占めないように)。

## Claude Code との進め方

レポートを読ませて、仮説 → 確認 → 対策の順で会話する。

```text
data/report.md を読んで、私の書き直しの癖を 3 つ挙げて。それぞれ根拠になった下書きの番号も添えて
```

```text
mid-edit で直している箇所に共通点はある? 語尾・敬語・前置き・言い換えなど種類ごとに分けて
```

```text
送信と破棄で書き方の違いはある? 破棄したものは何が原因で止めたと思う?
```

```text
この癖を減らすために、書き始める前に決めておくとよいことをチェックリストにして
```

数週間ごとに書き出し直して同じレポートを作り、前回と分布 (書き直し率・前の文を修正の割合) を比べると、癖が直っているかを確認できる。

## 構成

純粋な分析と IO を分けている。指標を足すときは `metrics.ts` → `aggregate.ts` → `report.ts` の順に広げる。

| ファイル       | 役割                                           |
| -------------- | ---------------------------------------------- |
| `text-diff.ts` | 文字単位の差分 (依存なし)                      |
| `metrics.ts`   | 下書き 1 件の指標と、履歴の変化の分類          |
| `aggregate.ts` | 切り口ごとの分布と、書き直しの多い下書きの抽出 |
| `report.ts`    | Markdown レポートの組み立て                    |
| `jsonl.ts`     | JSONL の読み込み                               |
| `cli.ts`       | ファイルの読み書き (`npm run analyze`)         |
